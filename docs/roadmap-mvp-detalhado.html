1 Pôr o site no ar (a base) · sem isto, nada converte

#Passo (o que fazer, em detalhe)QuemDestrava
1.1Supabase — criar projeto. Conta em supabase.com → "New project" → guardar a senha do banco.VOCÊsalvar leads
1.2Supabase — rodar os SQLs. No SQL Editor, colar e rodar (nesta ordem): supabase/schema.sql → supabase/payments.sql → supabase/fase-3-agents.sql (este último evita erro de tabela mais pra frente).VOCÊtabelas
1.3Supabase — chaves na Vercel. Project Settings → API → copiar e colar em Settings → Environment Variables (Prod+Preview): NEXT_PUBLIC_SUPABASE_URL e SUPABASE_SERVICE_ROLE_KEY (marcar Sensitive).VOCÊconexão
1.4Resend — conta + domínio. resend.com → Domains → adicionar foodguard.com.br → copiar os registros DNS e colar no seu registrador (onde comprou o domínio) → aguardar "Verified".VOCÊe-mail do relatório
1.5Resend — chave na Vercel. API Keys → criar → RESEND_API_KEY; e RESEND_FROM = Food Guard <diagnostico@foodguard.com.br>.VOCÊenvio
1.6Asaas — virar PRODUÇÃO. No Asaas, pegar a API Key de produção (não a sandbox) → na Vercel: ASAAS_API_KEY (produção), ASAAS_ENV=production, ASAAS_WEBHOOK_TOKEN (uma senha sua).VOCÊcobrar de verdade
1.7Asaas — webhook. No painel Asaas, apontar o webhook para https://SEU-DOMINIO/api/webhooks/asaas com o mesmo token do passo 1.6.VOCÊconfirmar pagamento
1.8Dados de contato e legais. Conferir na Vercel: NEXT_PUBLIC_SITE_URL (URL real), NEXT_PUBLIC_CNPJ, NEXT_PUBLIC_WHATSAPP, NEXT_PUBLIC_CONTACT_EMAIL, NEXT_PUBLIC_LEGAL_NAME.VOCÊrodapé/legal
1.9Domínio próprio. Apontar foodguard.com.br pra Vercel (Vercel → Domains + DNS no registrador). opcionalVOCÊmarca
1.10Calendly. Se for usar "agendar avaliação": criar evento → NEXT_PUBLIC_CALENDLY_URL. opcionalVOCÊCTA
1.11Teste final do fluxo no preview: diagnóstico → lead salvo no Supabase → e-mail chega (Resend) → pagamento de teste (Asaas).EUgarantir
1.12QA gate (Playwright MCP): testo o site, dou nota 0–100. ≥90 passa; <90 refaço.EUqualidade
1.13Publicar (produção). Push pra main → Vercel publica. Só com o seu "pode publicar".EUno ar 🚀
